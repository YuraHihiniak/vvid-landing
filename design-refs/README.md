## Палитра (из кадров и CSS)
- Hero / «clay»: терракота `#b9543f` → `#c9694e` → `#a4442d` (радиальный флуд).
- Светлый текст на тёмном: `#e4ded2`; тёмный текст: `#13110c` / `#1b1812`.
- Акцент (точка в логотипе, подчёркивания): `#b9543f`.
- Глубина фильма тонирована золотом-янтарём на почти чёрном.

## Заметки для дизайна
- Все средние блоки (услуги, кейсы, прайс, бриф) лежат поверх ОДНОГО непрерывного «нырка» —
  стебель → корни → почва → глубоководное существо. Текст всегда выключен влево, фон-3D справа.
- Hero и фильм — тёплые (красный/терракота); чем глубже, тем темнее и золотистее; FAQ и футер — плоский тёмный.
- Скриншоты 800 px по ширине (ограничение панели превью) — это композиционный референс, не финальное качество.
