# VVID — чистые фоны видео (без текста)

Это кадры скролл-фильма сайта в полном качестве, **без наложенного текста и UI** —
извлечены прямо из исходников (`film/*/hi/*.webp`), это те самые ключевые кадры,
которые автор отметил как опорные. Разрешение **2560×1440**.

- `*.webp` — оригиналы (2560×1440), открываются в Figma/Photoshop/Illustrator.
- `jpg/*.jpg` — те же кадры в JPG для максимальной совместимости.
- `hero-intro-video.mp4` — исходное зацикленное видео hero (фон первого экрана).

Текст блоков, который ложится поверх этих фонов, — в `../VVID.site-content.md`.
