# VVID — анимированные стикеры для Telegram

17 знаков из моушн-спеки `Эмодзи-моушн-спека.dc.html`, отрендеренные в `.webm`
для **анимированных стикеров Telegram**. Стиль сохранён 1:1: линейная
графика, кремовый штрих + терракотовый акцент, движение только `transform`+`opacity`,
бесшовный цикл.

## Как залить в Telegram

1. Открой **[@Stickers](https://t.me/stickers)** → `/newpack` → выбери тип **видео-стикеры**.
2. На каждый знак: отправь файл `.webm`, затем отправь **эмодзи-тег** из колонки
   ниже (это «подпись» — стандартный эмодзи, к которому привязывается анимация).
3. Готово — набор можно использовать в чатах (нужен Telegram Premium для отправки).

> Файлы соответствуют требованиям Telegram: **VP9 · 512×512 · 30 fps · ≤3 сек ·
> альфа-канал · без звука · ≤256 KB**. Машиночитаемая карта — `emoji-map.json`.

> Это набор **видео-стикеров** (512×512). Для **кастомных эмодзи** (100×100) используй соседнюю папку `tg-emoji/`.

## Замечание по теме оформления

Штрих кремовый (`#e4ded2`) — рассчитан на тёмный фон (как в дизайне). На **светлой**
теме Telegram линии будут малоконтрастными; терракотовый акцент остаётся читаемым.
Если нужен вариант под светлую тему — перекрасить штрих в тёмный (`#1b1812`) и
перегенерировать. Превью на обоих фонах — `index.html`.
